## 🔥 Pharo — Decentralized Insurance Protocol (Co-founder)  
**Role:** Co-founder • Full-Stack Engineer • Smart Contract Developer • Algorithm Designer  
**Tech:** Solidity • Python • TypeScript • Node.js • React/Next.js • EVM tooling  

### Overview  
Pharo is on-chain insurance against real-world events, built as an **Automated Coverage Maker**: an evolution of the AMM in which liquidity providers take on event risk and buyers are rewarded for entering early.

### Key Contributions  
- Designed the decentralized event algorithm and tokenomics  
- Designed Pharo tokens as a stablecoin tied to real-world events, minted and burned to keep payouts consistent as events unfold  
- Built the smart contracts, Python APIs, backend, and frontend
